First, load the ColecoVision BIOS

The ColecoVision can't switch on without the BIOS ROM chip Coleco built into it: every game calls routines in it. It is still under copyright, so it isn't included here: choose or drop your own BIOS image file. It stays in this browser and is never sent anywhere. The browser remembers it, so you only need to do this once.

ColecoVision BIOS ROM Required

The console's built-in 8K ROM, the same in every ColecoVision. Exactly 8 KB (8,192 bytes); the usual one has the CRC-32 checksum 3AA93EF3.

Often named coleco.rom, colecovision.rom, coleco.bin or BIOS.col. MAME keeps it in coleco.zip as 313 10031-4005 73108a.u2; the zip itself works too.

The retrobios collection keeps it in its ColecoVision folder.

Click or press a key to start sound

Keyboard (player 1): arrow keys for the joystick, Space or Z for the left button, X or C for the right one, the number keys for the keypad, with - for * and = for #. Gamepads work as soon as you press a button; the first is player 1, the second player 2. A is the left button, B the right; X and Y are * and #, Start is 1, Back/Select is 2, and the shoulder buttons are 3 and 4.
